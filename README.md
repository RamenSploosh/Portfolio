# My Art Portfolio

A beautiful, responsive portfolio website showcasing my art across multiple mediums and styles.

## Project Structure

```
Portfolio/
├── index.html                    # Main home page
├── css/
│   └── style.css                # Shared styles for all pages
├── js/
│   └── script.js                # Shared JavaScript functionality
├── projects/
│   ├── animation.html           # Animation project page
│   ├── illustration.html        # Illustration project page
│   ├── zines.html              # Zines project page
│   ├── copracorn.html          # Copracorn project page
│   ├── daily-pokemon.html      # Daily Pokemon project page
│   ├── graphic-design.html     # Graphic Design project page

├── assets/

│   ├── videos/                 # Video files
│   └── projects/               # Project-specific assets

```

## Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop devices
- **8 Art Categories**: Showcase your work across multiple mediums
  - Animation
  - Illustration
  - Zines
  - Copracorn
  - Daily Pokemon
  - Graphic Design
  - Photography
  - Other
- **Smooth Navigation**: Easy navigation between home and project pages
- **Modern Styling**: Clean, professional design with smooth animations
- **About & Contact**: Sections for personal information and contact details

## Getting Started

1. **Add Your Content**:
   - Edit the About section in `index.html` with your bio
   - Update contact information with your email and social media links
   - Add your artwork to the gallery sections on each project page

2. **Add Images/Media**:
   - Create an `assets/` folder to organize your images and videos
   - Update the placeholder gallery items with actual image paths
   - Replace background color placeholders with actual artwork

3. **Customize Colors**:
   - Each project page has a unique color scheme (defined in the `project-header` style)
   - Feel free to adjust these colors in the HTML files to match your brand

4. **Deploy**:
   - Push your changes to GitHub
   - Enable GitHub Pages in your repository settings
   - Your portfolio will be live at `https://RamenSploosh.github.io/Portfolio`

## Customization Tips

- **Fonts**: Change the default font in `css/style.css` by modifying the `font-family` property
- **Colors**: Update color values throughout the CSS file to match your aesthetic
- **Layout**: Adjust grid sizes and spacing in the responsive media queries
- **Navigation**: Add or remove links in the navbar as needed

## File Sizes & Performance

Keep these best practices in mind:
- Optimize images to reduce file size without sacrificing quality
- Use modern image formats (WebP, PNG, SVG where appropriate)
- Lazy load images if you have a large portfolio
